# Planejamento - Sistema de estoque

##1 - Visão Geral
-   O sistema de estoque fornece controle de ativos, cadastro, consulta, exclusão e alteração de produtos em estoque, assim como seus atributos. 
-   Atende pequenas e médias empresas/empreendimentos que necessitam controlar ativos e gerenciar melhor suas operações.
-   O sistema, por enquanto não possui métodos de login para mais de um usuário ou perfil.
Não possui mais de um estoque e localidade diferentes, impossibilitando transferências por agora.

##2 - Requisitos funcionais
O que o sistema deve permitir fazer.
- Cadastrar produto
- Registrar entrada
- Registrar saída
- Consultar produto
- Consultar movimentações
- Listar produtos
